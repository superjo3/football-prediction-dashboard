# 英超單雙 Sparse R1-85｜V3 極端條件共振研究

**研究日期：2026-11-27（台北）**  
**狀態：RESEARCH_ONLY / NO_PROMOTION / 原始賽前預測不變**

## 直接結論

本次沒有發現已驗證、可重複並維持超過 **85%** 的單雙 R1 規則。確有少數高於85%的**歷史表面數字**，但在新的時間區段失效。每輪最多 1 場 R1，無合格候選時 **PASS**；不強迫每輪選場。

## 研究輸入與限制

- 已封存的英超歷史快取涵蓋 2015–16 至 2025–26，4,180 場。本次以具備完整 `round` 的 2020–21 至 2025–26 **2,280 場、228 輪**研究。
- 16類賽前衍生特徵，包括平局／大小球市場機率、亞洲讓球幅度、近期進球與失球、近期單雙比例／連續紀錄、休息天數。檢查 **10,392 個單條或兩條條件交集**，每條各測「單／雙」。
- **2020–21** 兩季（76輪）只用於本版規則發現；**2022–23**（76輪）做時間後段檢驗；**2024–25**（76輪）是更後面的歷史對照。注意之前V1/V2已研究過2022–25的部分資料，因此全部都不能聲稱全新獨立盲測。
- 每輪在符合條件的比賽中，只選 **1場 R1**。預測「雙」時選市場平局機率最高的一場；預測「單」時選平局機率最低的一場；無合格比賽整輪 **PASS**。完整程式已鎖定此選場方法。
- 市場資料及特徵來自已封存快取，**沒有逐筆賠率商原始時間戳的獨立稽核**；不得冒稱 Bet365 OPEN／PRE-KICK 真實報價。

## V3主要規則：發現期最強但後段失效

固定規則：

```
goal_form_sum >= 5.5 AND odd_form_mean >= 0.6 => 單
```

`goal_form_sum` = 主隊近5場場均進球 + 客隊近5場場均失球 + 客隊近5場場均進球 + 主隊近5場場均失球；`odd_form_mean` = 主客隊近期5場單球數比率平均。

| 期間 | 選中 R1 | 命中率 | PASS 輪數 |
|---|---:|---:|---:|
| 2020–21 發現期 | 16/19 | 84.21% | 57/76 |
| 2022–23 時序驗證 | 9/23 | **39.13%** | 53/76 |
| 2024–25 歷史對照 | 12/24 | **50.00%** | 52/76 |

後段準確度嚴重反轉；**REJECT**。

## 小樣本「超過85%」陷阱

所有本次條件中，要求發現期至少18次 R1 時，**沒有任何規則超過85%**。放寬至8–17次，出現 **75條**發現期表面 >=85% 的稀疏規則；但其中**沒有一條**能在 2022–23 驗證期至少8次選場並維持 >=85%。

最好的小樣本歷史例子：

```
odd_form_sum10 <= 0.9 AND odd_streak_sum >= 2 => 雙
```

`odd_form_sum10` = 雙方近10場單球數比率總和；`odd_streak_sum` = 兩隊單雙連續狀態數值相加。此為探索後的篩選，不能視為預先通過的策略。

| 期間 | 命中率 | 是否達85% |
|---|---:|---|
| 2020–21 發現期 | **13/14 = 92.86%** | 表面達標 |
| 2022–23 驗證期 | **8/19 = 42.11%** | 未達標 |
| 2024–25 歷史對照 | **12/28 = 42.86%** | 未達標 |

因此即便容許大量 PASS，**也不能只挑歷史上命中率高的小樣本來冒稱85%**。

## 方向模型根本問題（既有V1前推分數複查）

2024–25 共760場，AUC（0.5約為無辨識力）：市場Logistic 0.467、近期狀態Logistic 0.501、綜合Logistic 0.482、梯度提升 0.472、隨機森林 0.469。這解釋為何用更嚴格的 confidence gate 仍無法穩定挑出85%。以上是**歷史回放**，並非 2026–27 新輪次前推結果。

## 決議

1. `EPL-SPARSE-R1-85` 保持「**每輪0–1場 R1，沒有合格就全部 PASS**」，目標依舊 **>85%**。已有三版舊規則都沒有達標；不加到 Official，不回頭改 GW11／GW12。
2. V3 所有高勝率候選均標 `REJECT_FOR_PROMOTION`；絕不由事後數字挑選排名。
3. 下一個有意義的突破必須換**新資訊來源**或**新方向模型**，如可核實的 Bet365 單雙盤口、開盤至T-60的盤勢變化、賽前可用低比分／和局聯動資訊和被嚴格定義的球隊陣容特徵；先獨立固定資料取得與條件，再用**未被拿來選規則的全新未來場次**逐輪驗證。
4. 報告同時列出 R1 命中數／選場數、各季命中、PASS 輪數、Wilson 95%信賴區間和原始資料品質。只有持續 >85%、足夠樣本與穩定前推才可討論升級。
