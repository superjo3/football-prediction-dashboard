# 英超單雙｜Sparse R1-only 85% 研究 V2

**日期：** 2026-11-27（台灣）  
**狀態：** `RESEARCH_ONLY / NO_PROMOTE / NO_OFFICIAL_CHANGE`  
**使用者變更：** 單雙高信心精選每輪可以**只選 R1 一場**，完全不要求 R2/R3；條件不合格時 `PASS`。目標為嚴格時間前推、樣本外 R1 命中率 **>85%**，而非全輪10場平均命中率。R2/R3 若出現在原 Official/Shadow 仍維持原有凍結，不能倒改。

## 資料與實驗

- 直接重用 V1 已封存的 `EPL_RESEARCH_ROLLING_MODEL_SCORES.csv`。共 1,900 場，2021–25 五個賽季；每個目標賽季的五種基礎模型只用之前賽季資料擬合，這次研究不重訓模型。
- **規則選擇期：2021–23**（114輪、1,140場）；**後段歷史評估：2024–25**（76輪、760場），後者在 V1 已經分析過，因此**不是全新盲測**。
- 七種模型/共振方向（五模型、均值、中位數） × 九種條件（共振、平局機率、大小球等） × 十一個門檻 = 693 種；另24種獨立「偏高平局機率、低大球機率 → 選雙」的條件；**717種選場規則**。
- 每輪從**符合門檻**的場次中最多挑一場，按模型信心分數排序，固定輸入排序作平手決勝；無符合者即 `PASS`。不能再事後替換命中率低的 R1。
- 研究期規則入選要求：至少30場、每個賽季至少5場（3個賽季），按 Wilson 95% 信賴區間下限最高選規則。**共有426個規則符合樣本要求，沒有任何一個的研究期命中率達85%。**

## 實測結果

| 指標 | 規則選擇期（2021–23） | 後段歷史評估（2024–25） |
|---|---:|---:|
| 選出的研究規則 | `rf_all__low_over__0.010` | 同一規則，不重新選參數 |
| 單雙 R1 命中 | **57/95 = 60.00%** | **22/48 = 45.83%** |
| 可選 R1 的輪次 | 95/114（83.33%） | 48/76（63.16%） |
| PASS 輪次 | 19/114 | 28/76 |
| Wilson 95% 區間 | 49.95%–69.28% | 32.58%–59.71% |

後段逐季：2024–25 命中 **7/17 = 41.18%**；2025–26 命中 **15/31 = 48.39%**。

研究規則的可計算定義：`rf_all`（V1已封存、按賽季前推訓練的隨機森林）估計 P(單)；只有歷史輸入 `p_over25 < 0.50` 且 `abs(P(單)-0.5) >= 0.01` 才合格。每輪選其中 `abs(P(單)-0.5)` 最大者，若無合格則 PASS。該規則**僅為檢驗對象，已因後段表現而判定 REJECT，不得導入正式預測**。

**更嚴格篩選也未改善：** 717種規則中，研究期至少20次 R1 之規則的最高表面命中率只有 **17/28 = 60.71%**；達到至少30次且三年均有足量選場的426種規則，**0種 ≥85%**。樣本少的高百分比不能代替穩健選場方法。

## 對照與解釋

- 不設門檻，`logit_form` 每輪只取一場：2024–25 為 **43/76 = 56.58%**。
- 全五模型一致的 `median + agree5` R1：**31/73 = 42.47%**。
- 隨機固定位置的「永遠選雙」（每輪首場）基準：**41/76 = 53.95%**。
- 因此 V2 篩選器不僅未達85%，實際還輸給若干簡單比較方式；目前不能 PROMOTE。

## 固定決議與下一步

1. **政策固定為「最多1場 R1，未達門檻就 PASS」，目標 >85%。** 未來真正的合格 R1 必須達到事前鎖定的門檻；顯示相對最佳候選不等於高信心合格。
2. **研究線保留為 V2-REJECT**，不得修改 GW11/GW12 已封存 Official、Recovery Shadow 預測、R位或賽果；不更新網站正式模型。
3. 若另研究新方向，應使用**新版本模型**增加比分相關性（尤其和局對「雙」的數學約束）、可驗證賽前 OU/AH 賠率變化、球隊特徵及誤差校準；固定閾值後使用**未參與規則挑選的未來賽事**前推。不得將過去看過的2024–25資料再自稱盲測。
4. 未來報告必須同時列 `qualified_R1_hits/qualified_R1_count`、選中輪次／總輪次、每季分布、PASS次數與95%區間；若只有極少數選場，標記 `INSUFFICIENT_SAMPLE`。
