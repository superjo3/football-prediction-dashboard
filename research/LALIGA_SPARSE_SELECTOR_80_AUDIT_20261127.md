# 西甲單雙 Sparse Selector ≥80%｜歷史前推研究（2026-11-27）

**狀態：NO_VALIDATED_80_RULE / PROMOTE NONE / RESEARCH ONLY。** 80% 是目標，尚未找出跨年度穩健達標的規則。這份報告只追加研究紀錄，不改 A/B/C 模型、GW14 賽前方向或 Official 結算。

## 資料與方法
- 歷史資料：2020–21 至 2025–26 六季共 2,280 場；2022–23 至 2025–26 按年份前推共 1,520 場。
- B：用已封存 StandardScaler + LogisticRegression(C=0.3) 按年份使用當年前期歷史訓練；特徵採原始可重播歷史計算，不使用當週賽果。
- C-style：固定 `0.30*XOR5 + 0.40*(1-Pdraw)*P(odd|non-draw of previous seasons) + 0.30*TOTAL5`。這是**C 歷史代理方法，非 GW13 C 的逐場 Exact 重現**；A 人工定性 V2 也沒有可回播的六季 Exact 歷史。
- 用 2022–23、2023–24 兩季（760 場）尋找規則；2024–25（380 場）驗證；2025–26（380 場）最後時間留出。檢查 282 個固定選場方案（不同 gate 與每週最多選 1/2/不限）；先要求尋規則的兩季至少選 25 場且勝率 ≥63%，才送入後面年份評估。最後兩季不可反向修參數。
- 2026–27 GW1～GW12 共 119 場只作**已看過賽果的回溯對照**，不是新盲測。2026–27 當季市場來源與六季原始 Bet365 資料並非完全同源。

## 真正檢查的成績
| 固定方案 | 歷史前推 2022–26 | 命中率 |
|---|---:|---:|
| B EXTENDED：全部方向 | 754/1520 | 49.6% |
| C-style 歷史代理：全部方向 | 741/1520 | 48.8% |
| B 既有 strict gate：`abs(B-.5)>=.08`、B/XOR/TOTAL 同向、雙隊近期樣本≥4 | 37/83 | 44.6% |
| B/C 同向 | 479/983 | 48.7% |
| B/C 同向且 B margin≥.08 | 120/259 | 46.3% |
| B/C 同向且 B margin≥.08 且 C margin≥.10 | 4/10 | 40.0% |

**候選 1**：B/C 同方向且兩者都選「單」、B margin≥.08；同一日曆週最多 1 場，按 min(B,C margin) → B margin → 球隊名稱做固定排序。
- 2022–24 發現：30/43，69.8%；
- 2024–25 驗證：11/21，52.4%；
- 2025–26 留出：5/15，33.3%；
- 後兩季合併：16/36，**44.4%** ⇒ **REJECT**。

**候選 2**：同條件改 B margin≥.10。
- 發現 20/30，66.7%；後兩季 10/23，**43.5%** ⇒ **REJECT**。

2026–27 GW1～GW12 的 B/C 同向 + B margin≥.08 雖有 **5/6＝83.3%**，但 95% Wilson 區間為約 43.6%～97.0%，不能宣稱真實勝率 ≥80%；歷史同規則只有 46.3%。更嚴格同向且雙 margin gate 只有 2/2，亦不足以採用。

## 判定與下一步
1. **拒絕**把這些回溯的「83%／100%」升成正式 selector；原西甲 A、B、C 及 GW14 封存完全保留。
2. 先將本次測試列為 `LALIGA-SPARSE80-EXPLORATORY-V0`（research negative-control, NO PROMOTION）；保存失敗條件，禁止賽後重挑。
3. 下一批未參與條件選擇的固定前推輪次，繼續記錄整輪、每個 R 位、樣本數、PASS 比例與信賴區間。若沒有足夠新樣本，就不能把 80% 當成可靠規則。
4. 必須與每輪全單／全雙、既有 B/C、基準順位比較；同源且有時間戳的 Bet365 OPEN／T-60 賠率缺失，禁止用回溯市場價替代。
5. **正式高信心未達條件時 PASS**。沒有為了湊 R1/R2/R3 而自動升格。
