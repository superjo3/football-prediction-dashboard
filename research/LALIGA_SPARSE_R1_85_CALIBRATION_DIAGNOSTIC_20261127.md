# LaLiga Sparse R1-only 85%｜信心校準問題稽核

研究階段：探索性診斷，2026-11-27。**未發現可驗證85%規則；不得升級成正式精選。**

資料：先前同一份四季前推代理檔 `historical_walkforward_features_2022_2026.csv`，2022–23 至 2025–26，1,520 場。B 為六季研究中所用逐季前推 EXTENDED，C 為 C-style proxy，不等於本季 C Exact；此資料已被研究者觀察過，因此下列分析不能視為嶄新 blind test。

| 項目 | 實績 | 備註 |
|---|---:|---|
| 四季實際單數基準 | 801/1520 = 52.7% | 全選單，不是精選模型 |
| B 整輪方向 | 754/1520 = 49.6% | 比全單基準低 |
| C-style proxy 整輪方向 | 741/1520 = 48.8% | 不是 GW13 C Exact |
| B 信心差距全體最高5% | 33/76 = 43.4% | 平均表面信心約66.3%，實際反而偏低 |
| C-style 最高5%信心差距 | 40/76 = 52.6% | 仍遠低85% |
| B/C 同向 | 479/983 = 48.7% | 共振不是獨立證據 |

## 結論
1. 現有 B/C 的 margin 門檻和同向共振不足以構成 85% 的可信門檻；提高門檻不能自動提高準度。
2. 先研究**方向模型與概率校準**、失誤條件，不能從這份已多次查閱的歷史集上調門檻直到碰到偶然85%。
3. R1-only 每官方GW最多一場；可跨多輪全部PASS；R2/R3不強制。正式/研究A-B-C既有紀錄與GW14封存方向完全不改。
4. 下次研究需另立時間隔離資料區，以官方GW分組、固定特徵與公開場數/覆蓋率/基準，且在評估新資料前封存完整code+inputs+rules+tie-break。
5. 在驗證新資料前，Sparse R1 = PASS / NOT_VALIDATED，**不是改選了更少場就有85%**。不宣稱任何投注保證或當前85%勝率。

附註：本診斷僅用先前產出的封存前推代理表作重新分組，沒有寫入、覆蓋或重算原有GW13/GW14賽前預測。
